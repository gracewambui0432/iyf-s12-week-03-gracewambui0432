## Project Description
This project is a personal portfolio website created to practice styling web pages with CSS. It introduces my background, interests, and web development journey while demonstrating how a website can adapt to different screen sizes.

The goal was to improve the appearance and usability of my portfolio while applying the CSS concepts covered in Week 2.

## Technologies Used
- HTML5
- CSS3

## Features
- Responsive navigation with a CSS-only hamburger menu
- Portfolio introduction and profile image
- Sections for hobbies, interests, and contact information
- CSS styling for colors, typography, spacing, and page layout
- Flexbox and Grid layouts for organizing content
- Box model practice with margin, padding, borders, and content sizing
- Hover and focus styles for interactive elements
- Responsive layout adjustments for different screen sizes

## How to Run
1. Clone this repository:
2. Open the project folder.
3. Open `index.html` in your browser.

No package installation is required.

## Lessons Learned
- How to connect an external CSS stylesheet to an HTML page
- How the CSS box model affects element size and spacing
- How Flexbox and Grid help organize page content
- How to use media queries to make layouts responsive
- Why consistent class names and organized CSS rules make styling easier to maintain

## Challenges Faced
One challenge was keeping the layout consistent across different screen sizes. I worked on this by using responsive CSS rules and testing the page at different viewport widths.

I also encountered styling conflicts caused by repeated selectors in my stylesheet. Reviewing and organizing the CSS helped me understand how the cascade and specificity affect the final appearance of a page.
